# NeuralForge 🧠 — AI Dev Platform

World's first Autonomous AI Development Intelligence Platform built in Java. Generates full-stack features from plain English, predicts bugs before runtime, self-heals production errors, and features a 3D neural dashboard.

## 🚀 Features
- Generate full-stack features from plain English using GPT-4o
- Bug prediction before runtime (Bug Oracle)
- Self-healing production errors
- 3D neural dashboard
- Vector memory for context-aware AI
- Real-time Kafka event streaming
- Redis caching layer

## 🛠️ Tech Stack
- **Backend:** Java 21, Spring Boot 3, LangChain4j, GPT-4o
- **Frontend:** React
- **Infra:** Docker, Kafka, Redis
- **AI:** GPT-4o, LangChain4j, Vector DB

## ⚡ Quick Start
```bash
# Start all services
docker-compose up --build
```

Open [http://localhost:3030](http://localhost:3030) in your browser.
