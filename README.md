## ✨ Features

| Feature | Description |
|---|---|
| 🤖 **Intent to Feature** | Type plain English → get full-stack code generated by GPT-4o |
| 🔮 **Bug Oracle** | Predicts bugs before they hit runtime using AST analysis |
| 🛡️ **Self-Healing Runtime** | Automatically detects and fixes production errors |
| 🧬 **Vector Memory** | Context-aware AI with persistent vector memory |
| 📡 **Live Code Consciousness** | Real-time WebSocket streaming of AI decisions |
| 🧠 **3D Neural Dashboard** | Beautiful React dashboard with live stats |
| ⚡ **Kafka Streaming** | Real-time event pipeline for AI operations |
| 🗄️ **Redis Caching** | High-performance caching layer |

## 🛠️ Tech Stack

### Backend
- **Java 21** + **Spring Boot 3**
- **LangChain4j** + **GPT-4o** — AI engine
- **Spring Security** + **JWT** — Authentication
- **PostgreSQL** + **Flyway** — Database & migrations
- **Apache Kafka** — Event streaming
- **Redis** — Caching
- **WebSocket** — Real-time communication
- **GraphQL** — Flexible API queries

### Frontend
- **React** + **TypeScript**
- **Vite** — Build tool
- **Tailwind CSS** — Styling
- **Zustand** — State management

### Infrastructure
- **Docker Compose** — Full-stack orchestration
- **Kubernetes** — K8s deployment configs
- **Terraform** — Infrastructure as code
- **Prometheus** — Monitoring

## ⚡ Quick Start

### Prerequisites
- Docker & Docker Compose
- OpenAI API Key

```bash
# Clone the repo
git clone https://github.com/PAVANRYADUVANSHI/NeuralForge.git
cd NeuralForge

# Copy and fill env vars
cp .env.example .env
# Add your OPENAI_API_KEY in .env

# Start all services
docker-compose up --build
```

Open [http://localhost:3030](http://localhost:3030) in your browser.

### Manual Setup

```bash
# Backend (Java)
cd backend
./mvnw spring-boot:run

# AI Engine
cd ai-engine
./mvnw spring-boot:run

# Frontend
cd frontend
npm install
npm run dev
```
